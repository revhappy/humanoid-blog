## REPLY templates (paste under relevant posts — customize)

**Under a polished autonomy demo:**
```
Looks clean on camera. Is this supervised, scripted, or unsupervised for a full shift? The answer changes the story.
```

**Under a mega-round with no product:**
```
Runway isn’t product. What’s the first paid deployment, and what does an hour of useful work cost the customer?
```

**Under “we’ll replace all factory labor”:**
```
Start with one cell, one SOP, one safety case. Replacement rhetoric is cheap; takt time isn’t.
```

**Under home-robot vapor:**
```
Price, city, what’s off-limits, and whether a human is still in the loop. Without those, it’s a concept trailer.
```

**Under Chinese volume claims:**
```
Volume claims matter if field support and failure rates travel with them. Units shipped ≠ units still working six months later.
```

**Under “AI will solve robotics end-to-end”:**
```
Models help. So do force control, cycle time, and who shows up at 2 a.m. when the tote jams. Full stack is still full stack.
```
